01-idea.md · 7 sections

The idea

Problem

FCI Cyber (Paramus, NJ; managed cybersecurity for financial-services firms since 1995) is hiring a remote Junior Application Developer to build two Retool portals from detailed plans: a client portal where security officers see their devices and posture, and an internal portal replacing manual ops processes. Stack: self-hosted Retool, JavaScript transformers / JS queries, PostgreSQL, REST APIs, Retool Workflows with conditional logic. They want solid JS + SQL, shipped work, following a plan faithfully and speaking up when reality diverges, and they are AI-first with Claude Code in the official workflow. Luqman has none of this in Retool yet.

Proposed solution

Build both portals in miniature on one Postgres database with fictional firms and devices. A fake vendor API with messy data feeds a nightly Retool Workflow; the real endoflife.date API flags unsupported operating systems. Logic is written and tested in plain JS outside Retool. The work follows PLAN.md, and every divergence is logged in DEVIATIONS.md before the plan changes.
